Shtorka, a Mac menu bar panel

Claude, clipboard, notes, apps and music in one panel on a hotkey

My own project · Case author: Zakhar Sokolinsky

Before

Every day I jumped between the terminal, notes, the clipboard and app launching, and Claude was never at hand.

What was done

  • Built a native app: it lives in the menu bar and opens over every window on one hotkey
  • Five tabs in one window: Claude, clipboard history, notes, app launcher and music
  • Claude runs on the Claude Code subscription - no API keys, no per-request cost
  • Reads text from screenshots, takes voice input and starts at login

Result

The app is built and used every day. It is a personal tool, not published in a store, so there are no audience numbers.
