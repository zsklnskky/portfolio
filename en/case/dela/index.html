Dela, a task tracker with timers

Every task has its own timer, and live charts show where the time went

My own project · Case author: Zakhar Sokolinsky

Before

Tasks lived in different places, and how much time each one really took was invisible.

What was done

  • Built a Mac app: a task table where every task has its own real-time timer
  • Added live charts: statuses and time per task are visible at once
  • Progress saves itself to a local file and never leaves the computer
  • The interface is HTML inside a native shell - fast to restyle, still a normal app

Result

The app is built and runs with autosave. It is a personal tool, so there are no user metrics.
