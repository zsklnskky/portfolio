Site and bot for a tattoo studio

A site request reaches the artists in Telegram with a price estimate, and a bot edits the site by message

INKSIDE tattoo studio, Minsk · Case author: Zakhar Sokolinsky

Before

Bookings came only via Instagram, and every site edit needed a developer.

What was done

  • Built a site with a price calculator and three-step booking: style, placement, size
  • The request with the estimate goes straight to the artists' Telegram group
  • The bot reminds the team if a request waits too long
  • An artist messages the bot and prices, texts or photos change on the site
  • Wrote 19 service pages and an 11-page audit with an ad plan

Result

SEO 100 in Lighthouse, the site and bot run since 14 October 2026.
